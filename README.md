# Personal Portfolio Website

A modern, responsive personal portfolio application built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**. Smooth interactions and animations are powered by **Framer Motion**.

---

## 🚀 Tech Stack

- **Framework:** [Next.js]
- **Library:** [React 19]
- **Language:** [TypeScript]
- **Styling:** [Tailwind CSS]
- **Animations:** [Framer Motion]
- **Icons:** [Lucide React], [React Icons]
- **Theme:** [next-themes]

---

## 📁 Folder Structure

```text
├── app/                  # Next.js App Router pages and layouts
│   ├── projects/[id]/    # Project detail pages
│   └── page.tsx          # Home page
├── components/           # Reusable UI components
├── data/                 # Static data & project details
└── public/               # Public assets (images, icons, etc.)
```
